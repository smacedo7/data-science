# Data Science Studies

A collection of projects, exercises, and notes documenting my learning journey in Data Science with Python.

## Topics

- **Data Analysis:** data cleaning, transformation, and exploration.
- **Data Visualization:** charts and visual storytelling.
- **Statistics:** descriptive statistics, probability, and hypothesis testing.
- **Machine Learning:** data preprocessing, model training, and evaluation.

## Tools and Libraries

Tools used throughout the repository may include:

- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Repository Structure

Content is organized by topic or project. Each folder may contain notebooks, datasets, and supporting notes.

## Getting Started

Clone the repository and navigate to the notebook or project you want to explore. Follow its setup instructions to install the required dependencies.

## Learning Goals

- Build a solid foundation in statistics and data analysis.
- Explore real datasets and communicate findings clearly.
- Understand how machine learning models work and how to evaluate them.
- Develop reproducible workflows through hands-on practice.
